# 🐰 NewJeans Store

### 💙 A NewJeans Fan Store Experience 💗

**E-commerce fan-store bertema NewJeans** yang dibangun menggunakan Laravel.

Belanja album & merchandise, simpan produk favorit ke wishlist, dan baca berbagai konten menarik melalui **Magazine** — semuanya dalam satu tempat untuk para Bunnies. 🐇

## ✨ Features

| Feature                 | Description                                            |
| ----------------------- | ------------------------------------------------------ |
| 🛍️ **Product Catalog** | Browse albums and merchandise with category filtering  |
| 🖼️ **Product Gallery** | View detailed product information with multiple photos |
| 🛒 **Shopping Cart**    | Add, update, and review products before checkout       |
| 💳 **Checkout**         | Complete the ordering process                          |
| 💜 **Wishlist**         | Save favorite products for later                       |
| 📰 **Magazine**         | Read fan-content and articles about NewJeans           |
| 🔐 **Authentication**   | User registration and login system                     |
| ⚙️ **Admin Dashboard**  | Manage products, categories, articles, and orders      |
| 📦 **Order Management** | Monitor and update incoming customer orders            |

---

| ------------- | -------------- |

| 🖌️ Styling   | Tailwind CSS 4 |
| ⚙️ Backend    | Laravel 12     |
| 🗄️ Database  | SQLite         |
| 📦 Build Tool | Vite           |
| 🌐 Hosting    | InfinityFree   |
| 💻 Language   | PHP            |
